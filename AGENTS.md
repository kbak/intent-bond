# Working on IntentBond

For repository changes, use the packaged
[IntentBond development skill](intentbond/skills/intentbond/SKILL.md).
Follow its linked references as needed for the task.

The user outcomes are in [docs/intent.md](docs/intent.md), the maintained technical
contract is [docs/spec.md](docs/spec.md), and the checking policy is
[scope.json](scope.json). Follow their trace links and keep affected intent, requirements,
reference docs, code, and tests consistent in each commit, following
[CONTRIBUTING.md](CONTRIBUTING.md#make-a-change).

Use the accepted baseline for ordinary development. Recovery guidance documents
initial onboarding; existing requirements are maintained directly.
